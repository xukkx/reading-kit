# 📘 使用说明 — 读书系统怎么用

> 只需要记住一件事：**左边栏的 📖 图标**（book-open）。点它，所有功能都在菜单里。
> 忘了任何操作就回这一页（问答面板里也有「📘 使用说明」按钮直达）。

## 🔁 日常读书的完整动作

1. **打开书**：`Books/` 文件夹 → 选一本 → `正文`
2. **看结构**：右上角大纲（Outline）面板 = 章节目录，点击跳转
3. **跳页码**：📖 菜单 → 🔢 跳转页码 → 输入页码回车（正文里的 ﹝55﹞ 小灰字就是原书页码）
4. **划线写想法**：**选中文字 → 等半秒 → 弹出小工具条** → ✍️ 批注 → 写想法 → 保存
   - 想法存进本书旁边的 `批注.md`（带页码），原文自动变==绿色高亮==
5. **有疑问就问**：选中文字 → 小工具条 → ❓ 问AI；或打开 💬 面板直接提问
   - 回答带来源编号，点来源可跳到那一页
   - 好答案点 **💾 存入笔记** 存档
6. **收工前**：📖 菜单 → 🔄 重建知识库索引 —— 这一步让今天的批注变成 AI 明天能引用的知识

## 🧠 它是怎么连起来的

```
你的划线批注、读书笔记、AI 存档 ──全部存为 vault 里的 md 文件
        ↓ 重建索引后
问 AI 任何问题 → 它检索这些笔记回答你（含你自己的批注）
```

## ⚙️ 前提（电脑端，开一次就行）

AI 问答需要电脑上跑着服务：终端进入项目文件夹，运行
`python scripts\rag.py serve`
手机/平板使用时，在插件设置里把地址改成电脑的局域网 IP（如 `http://192.168.1.5:8766`），两台设备连同一个 Wi-Fi。

## 🆘 常见问题

| 症状 | 解法 |
|---|---|
| 问 AI 报错 ⚠️ | 电脑上的 `rag.py serve` 没在跑，跑起来即可 |
| 小工具条没弹出 | 多选一点字（≥2字），等半秒；或右键菜单 / `Ctrl+P` 搜「批注」 |
| 找不到某功能 | 一律：左边栏 📖 图标 → 菜单 |
| 新批注 AI 搜不到 | 📖 菜单 → 🔄 重建知识库索引 |
