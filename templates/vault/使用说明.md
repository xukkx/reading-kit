# 📘 使用说明 — 读书系统怎么用

> 整个系统长什么样？一张图：[[系统架构]]

> 只需要记住一件事：**左边栏的 📖 图标**（book-open）。点它，所有功能都在菜单里。
> 忘了任何操作就回这一页（问答面板里也有「📘 使用说明」按钮直达）。

## 🔁 日常读书的完整动作

1. **打开书**：`Books/` 文件夹 → 选一本 → `正文`
2. **看结构**：右上角大纲（Outline）面板 = 章节目录，点击跳转
3. **跳页码**：📖 菜单 → 🔢 跳转页码 → 输入页码回车（正文里的 ﹝55﹞ 小灰字就是原书页码）
4. **划线写想法**：**选中文字 → 等半秒 → 弹出小工具条** → ✍️ 批注 → 写想法 → 保存
   - 想法存进本书旁边的 `批注.md`（带页码），原文自动变==绿色高亮==
5. **有疑问就问**：选中文字 → 小工具条 → ❓ 问AI；或打开 💬 面板直接提问
   - 回答带来源编号，点来源可跳到那一页
   - 好答案点 **💾 存入笔记** 存档
6. **收工前**：📖 菜单 → 🔄 重建当前收藏索引 —— 这一步让今天的批注变成 AI 明天能引用的知识（只重建你正在读的这个收藏，很快；多本书混杂在一起时才需要「重建全部收藏索引」）

> 📚 **书多了怎么办**：书按「收藏」分类存放（`Books/<收藏>/<书名>/`），每个收藏有自己独立的知识库——问 AI 时插件会根据你正在读哪本书自动检索对应收藏，不会把不相关的书混进答案里。

## 🧠 它是怎么连起来的

```
你的划线批注、读书笔记、AI 存档 ──全部存为 vault 里的 md 文件
        ↓ 重建索引后
问 AI 任何问题 → 它检索这些笔记回答你（含你自己的批注）
```

## 📱 手机 / 平板

- 同步与安装：看 [[同步设置]]（坚果云 + remotely-save，插件会跟着 vault 自动到手机）
- 手机上选中文字 → 小工具条出现在选区**下方**（避开系统菜单）→ ✍️ / ❓
- 📖 菜单在手机的左侧抽屉里；常用命令也可加到手机底部工具栏（设置 → Toolbar）

## ⚙️ 前提（电脑端，开一次就行）

AI 问答需要电脑上跑着服务：终端进入项目文件夹，运行
`python scripts\rag.py serve --port {{RAG_PORT}}`
插件设置「RAG 服务地址」`setup.ps1` 装的时候已经预填好了（`http://localhost:{{RAG_PORT}}, http://<电脑局域网IP>:{{RAG_PORT}}`），一般不用再手动填——有「测试连接」按钮可验证。

## 🆘 常见问题

| 症状 | 解法 |
|---|---|
| 问 AI 报错 ⚠️ | 电脑上的 `rag.py serve` 没在跑，跑起来即可 |
| 小工具条没弹出 | 多选一点字（≥2字），等半秒；或右键菜单 / `Ctrl+P` 搜「批注」 |
| 找不到某功能 | 一律：左边栏 📖 图标 → 菜单 |
| 新批注 AI 搜不到 | 📖 菜单 → 🔄 重建当前收藏索引 |
| 手机没有插件/书 | 看 [[同步设置]] —— 多半是没开「同步配置目录」 |
| 手机问 AI 报错 | 电脑要开着 serve，手机电脑同一 Wi-Fi；插件设置里点「测试连接」 |
