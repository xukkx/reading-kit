# 🔄 同步设置 — 手机/平板/多台电脑

方案：**remotely-save 插件 + 坚果云（WebDAV，免费）**。vault 是纯文件夹，同步它就同步了一切——笔记、书、批注、插件本身、使用说明。

## 第一步：坚果云（一次）

1. 注册 [坚果云](https://www.jianguoyun.com)（免费版每月 1GB 上传流量，够用）
2. 网页版 → 右上角账户 → **安全选项** → 第三方应用管理 → **添加应用**（名字随意，如 obsidian）→ 生成**应用密码**（记下来，这不是登录密码）

## 第二步：电脑端（一次）

1. Obsidian → 设置 → Community plugins → Browse → 搜 **remotely-save** → Install + Enable
2. remotely-save 设置：
   - 远程服务类型：**WebDAV**
   - 服务器地址：`https://dav.jianguoyun.com/dav/`
   - 用户名：坚果云注册邮箱；密码：**应用密码**
   - 远程基础目录：填一个专用名字，如 `obsidian-reading`
   - ⚠️ 关键：打开 **同步配置目录（.obsidian）** 选项 —— 插件、阅读排版、设置全靠它带到手机
3. 点 **保存并同步**（第一次全量上传，稍等）

## 第三步：手机/平板（每台设备一次）

1. 装 [Obsidian App](https://obsidian.md/mobile)（iOS/Android）→ Create new vault（名字随意）
2. 设置 → Community plugins → 关闭 Restricted mode → Browse → 装 **remotely-save**
3. 填与电脑**完全相同**的 WebDAV 配置（含同一个远程目录、打开同步配置目录）
4. 同步 → 等它拉完 → **重启 Obsidian** → 📖 阅读插件、书、批注全部就位

## 第四步：手机连 AI 问答（可选）

- 前提：电脑开着并运行 `python scripts\rag.py serve`，手机和电脑连**同一个 Wi-Fi**
- 插件设置「RAG 服务地址」填**两个**（电脑上填好即可，设置会同步）：
  `http://localhost:8766, http://192.168.x.x:8766`（后者是电脑的局域网 IP，setup.ps1 结束时打印过）
- 插件会自动选可用的地址；设置里有「测试连接」按钮
- 不在家/不同 Wi-Fi 时问答不可用（读书、批注不受影响，回家同步即可）

## 日常习惯

- 读完/批注完 → 点一下 remotely-save 的同步按钮（或开自动同步，间隔 30 分钟↑）
- **先同步再换设备**，避免两边同时改同一条笔记
- `90-Attachments` 里的 PDF 较大，第一次上传慢是正常的

## 常见问题

| 症状 | 解法 |
|---|---|
| 手机上没有 📖 插件 | 电脑端 remotely-save 没开「同步配置目录」；开了重新同步，手机拉取后重启 |
| 提示 WebDAV 401 | 用的是登录密码——要用**应用密码** |
| 两边冲突 | remotely-save 会保留双方版本；打开冲突文件手动合并 |
| 手机问 AI 报错 | 见 [[使用说明]] 常见问题；十有八九是电脑没跑 serve 或不同 Wi-Fi |
