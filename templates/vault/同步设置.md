# 🔄 同步设置 — 手机/平板/多台电脑

方案：**remotely-save 插件 + 坚果云（WebDAV，免费）**。vault 是纯文件夹，同步它就同步了一切——笔记、书、批注、插件本身、使用说明。

> ℹ️ **多个 reading-kit 项目共存时**：每个项目的本地文件夹都叫 `vault`，长得一样，但云端「远程基础目录」必须每个项目不同，否则会被同步成同一份、内容互相覆盖。这件事已经自动处理了——`setup.ps1` 装这个项目时，从全局注册表 `~\.reading-kit\registry.json` 分配了一个专属值，写进了下面第二步，不用你自己起名字/记名字。放心地照抄本文档里的值即可。任何时候想确认所有项目之间没有撞车，在任意一个项目里跑：`pwsh -File scripts\check_sync.ps1`

## 第一步：坚果云（一次）

1. 注册 [坚果云](https://www.jianguoyun.com)（免费版每月 1GB 上传流量，够用）
2. 网页版 → 右上角账户 → **安全选项** → 第三方应用管理 → **添加应用**（名字随意，如 obsidian）→ 生成**应用密码**（记下来，这不是登录密码）

## 第二步：电脑端（一次）

1. Obsidian → 设置 → Community plugins → Browse → 搜 **remotely-save** → Install + Enable
2. remotely-save 设置：
   - 远程服务类型：**WebDAV**
   - 服务器地址：`https://dav.jianguoyun.com/dav/`
   - 用户名：坚果云注册邮箱；密码：**应用密码**
   - 远程基础目录：**`{{REMOTE_DIR}}`**（本项目专属，直接抄这个值）
   - ⚠️ 关键：打开 **同步配置目录（.obsidian）** 选项 —— 插件、阅读排版、设置全靠它带到手机
3. 点 **保存并同步**（第一次全量上传，稍等）

## 第三步：手机/平板（每台设备一次）

1. 装 [Obsidian App](https://obsidian.md/mobile)（iOS/Android）→ Create new vault（名字随意）
2. 设置 → Community plugins → 关闭 Restricted mode → Browse → 装 **remotely-save**
3. 填与**这台电脑上这个项目**完全相同的 WebDAV 配置：远程目录同样填 `{{REMOTE_DIR}}`、打开同步配置目录。手机上如果装了不止一个 vault app（对应不同项目），每个 vault 要填各自项目的远程目录，不能都填一样的
4. 同步 → 等它拉完 → **重启 Obsidian** → 📖 阅读插件、书、批注全部就位

## 第四步：手机连 AI 问答（可选）

- 前提：电脑开着并运行 `python scripts\rag.py serve --port {{RAG_PORT}}`，手机和电脑连**同一个 Wi-Fi**
- 插件设置「RAG 服务地址」`setup.ps1` 已经预填好（`http://localhost:{{RAG_PORT}}, http://<电脑局域网IP>:{{RAG_PORT}}`），设置会跟着 vault 同步到手机，一般不用手动填。有「测试连接」按钮可验证；连不上再手动改
- 插件会自动选可用的地址
- 不在家/不同 Wi-Fi 时问答不可用（读书、批注不受影响，回家同步即可）

## 日常习惯

- 读完/批注完 → 点一下 remotely-save 的同步按钮（或开自动同步，间隔 30 分钟↑）
- **先同步再换设备**，避免两边同时改同一条笔记
- `90-Attachments` 里的 PDF 较大，第一次上传慢是正常的

## 常见问题

| 症状 | 解法 |
|---|---|
| 手机上没有 📖 插件 | 电脑端 remotely-save 没开「同步配置目录」；开了重新同步，手机拉取后重启 |
| 提示 WebDAV 401 | 用的是登录密码——要用**应用密码** |
| 两边冲突 | remotely-save 会保留双方版本；打开冲突文件手动合并 |
| 手机问 AI 报错 | 见 [[使用说明]] 常见问题；十有八九是电脑没跑 serve 或不同 Wi-Fi |
| 两个不相关项目的笔记混在一起了 | 远程基础目录填重了。正常情况下不会发生（`setup.ps1` 自动分配、彼此不同）——只会发生在手动改过配置时。跑 `pwsh -File scripts\check_sync.ps1` 定位哪两个项目撞车了 |
