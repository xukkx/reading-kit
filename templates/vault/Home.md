欢迎来到你的知识库。所有笔记都是普通 `.md` 文件，`[[双链]]` 自动生成右上角的知识图谱（Ctrl+G）。

## 分区

| 文件夹 | 放什么 |
|---|---|
| `00-Inbox` | 快速捕捉、未整理的想法 |
| `10-Notes` | 永久笔记（一条笔记一个想法） |
| `20-Literature` | 书籍/论文的文献笔记 |
| `30-MOCs` | 主题地图（索引笔记） |
| `Books` | 重排好的阅读版书籍（选中文字即可批注/问AI） |
| `90-Attachments` | PDF、图片等附件 |

## 配套 Claude Code 技能

在项目文件夹里对 Claude 说：

- `/read-book <pdf路径>` — 导入一本书：OCR → 校验 → 重排成阅读版 → 陪你精读批注
- `/note <任何想法>` — 把想法变成带链接的永久笔记
- `/organize-vault` — 整理知识库：找孤儿笔记、补链接、更新地图
